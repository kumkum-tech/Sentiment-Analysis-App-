# 😊 Sentiment Analysis App

A Machine Learning and Natural Language Processing (NLP) based web application that analyzes user-entered text and predicts its sentiment as **Positive**, **Negative**, or **Neutral**. Built using **Python**, **Scikit-learn**, and **Streamlit**, this project demonstrates the practical application of text preprocessing, TF-IDF vectorization, and sentiment classification.

## 📖 Project Overview

Sentiment Analysis is a Natural Language Processing (NLP) technique used to determine the emotional tone behind a piece of text. This application allows users to enter any sentence and instantly receive a sentiment prediction generated by a trained Machine Learning model.

The project leverages TF-IDF Vectorization for text feature extraction and a trained classification model for accurate sentiment prediction.

## ⚙️ How It Works

### Step 1: User Input

The user enters a sentence or text through the Streamlit interface.

### Step 2: Text Vectorization

The input text is transformed into numerical features using a TF-IDF Vectorizer.

### Step 3: Sentiment Prediction

The trained Machine Learning model processes the transformed text and predicts the sentiment category.

### Step 4: Display Result

The predicted sentiment is displayed instantly to the user.
